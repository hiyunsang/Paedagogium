# Paedagogium

정보·컴퓨터 중등 임용 서재 — 공부 자료, 오답 노트(간격 반복), Claude 튜터(질문·답안 만들기·문제 만들기·서술형 채점),
그리고 교육청·평가원·한능검 **중요 공지**와 서울·경기 **정보 과목 구인 공고**를 모아 주는 로컬 프로그램.
Athenaeum 과 같은 꼴(로컬 서버 + 브라우저 창, 데이터는 이 폴더에만, Claude 는 구독 사용량으로 `claude -p`).

## 켜기
바탕화면의 **Paedagogium** 아이콘, 또는 `app\Paedagogium_실행.bat`. 주소는 http://localhost:8772

필요한 것: Python 3.8 이상(PATH), Claude Code(로그인된 `claude`). Claude 가 없어도 공부 자료·오답 노트·공지·구인은 쓸 수 있다.

## 화면
| 화면 | 들어 있는 것 |
|---|---|
| 개요 | D-day, 이번 주 할 일, 꼭 볼 공지, 마감 임박 구인, 다가오는 시험, 임용 1차 일정·구성·출제 비율·범위·선발 인원, 공식 자료 |
| 중요 공지 | 서울·경기 임용 게시판, 평가원 기출(정보·컴퓨터 문제지)·공지, 한능검 공지. 공지마다 Claude 의 ‘할 일 정리’(첨부 한글 공고문까지 읽음), 날짜는 일정에 추가 |
| 구인 공고 | 정보 과목 기간제·시간강사·사립 정규, 이번 주 마감·면접 달력, 첨부 공고문의 일정 |
| 공부 길잡이 · 임용 표준안 · 교육과정 요약 · 기출 정리 · 교과교육학 | claude.ai 판의 공부 자료 그대로 (진도 체크, 서술형 연습 채점) |
| 오답 노트 | 1·3·7·14·30일 간격 반복, Claude 해설(요지 먼저) |
| 질문하기 | 질문 / 답안 만들기 / 문제 만들기, 대화 여러 개, 답이 쓰이는 대로, 멈추기 |
| 기록·설정 | 백업 내려받기·불러오기, Claude 계정(Athenaeum 전용 계정과 같이 쓰기)·모델, 공지 정리에 쓰는 내 정보 |

개발 안내는 `CLAUDE.md`.
